# PowerZone - Tienda Deportiva Online

PowerZone es una tienda Online moderna diseñada para los amantes del deporte. El proyecto esta enfocado en ofrecer una experiencia de usuario fluida, aquí encontraras productos de las categorias Fútbol, Baloncesto, Natación y Running.

## 🚀 Características Principales
* **Catálogo de productos:** Los productos se renderizan dinámicamente desde un array de objetos con JavaScript, facilitando la escalabilidad. 

* **Interfaz de Impacto** Cuenta con un carrusel personalizado con captions flotantes.

* **Diseño Responsivo** Construido con Bootstrap 5, garantizando que la tienda se pueda ver desde cualquier dispositivo. 

* **Carrito de Compras** Cuenta con la funcionalidad lógica para agregar productos mediante atributos data- y tiene persistencia usando localStorage. 


## 🛠️ Tecnologías Utilizadas
